## What is Artifacts?

Artifacts is a MMO game that purely is run through API calls, so of course you can setup an API in any language and create scripts\
Generally this is done in js or python but I wanted to better my Java so I decided to do it in Java :)

## General

The project will ideally be running via a local machine I have at home making these api calls \
Ideally I will make a console interface for running the "app" that does all the handling in the background while I (the user) can remotely access and check my character at any point\
So in theory I also need a way to store data and such which is why I plan to create classes for my character and similar aspects like enemies, etc..

### Launching
I mean its made to run on a low ram local linux machine but you can run it on windows terminal if you want...

!!IMPORTANT!! \
you first need to create a .env file in root of this project and include ARTIFACTS_API_KEY = xxx (On account page after signing up at https://www.artifactsmmo.com/)\
I could've had you paste your API key everytime you launch the app but thats a hassle so just once off create a .env in the root
